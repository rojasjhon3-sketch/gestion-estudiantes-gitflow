# Sistema de Gestión de Estudiantes

Aplicación CRUD desarrollada con HTML, CSS y JavaScript puro.

## Funcionalidades
- Registrar estudiantes.
- Consultar el listado de estudiantes.
- Editar registros existentes.
- Eliminar registros con confirmación.
- Buscar por nombre, matrícula, correo o carrera.
- Validar campos obligatorios y evitar matrículas duplicadas.
- Guardar los datos en `localStorage` del navegador.

## Cómo ejecutar
1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador moderno.
3. Los registros se guardan localmente en el navegador utilizado.

## Tecnologías
- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage

## Nota
Este proyecto es una aplicación de demostración académica. LocalStorage guarda los datos en el navegador y no proporciona almacenamiento compartido entre distintos dispositivos o usuarios.
